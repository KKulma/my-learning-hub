# Plan Agile with GitHub Projects and Azure Boards

Azure Boards have direct integration with Azure Repos, but they can also be integrated with GitHub to plan and track work by linking commits, pull requests, and issues.

User-owned project boards can contain issues and pull requests from any personal repository.

Automated CMMI is not a Project Boards supported template by default, but basic Kanban and automated Kanban with review are supported.
